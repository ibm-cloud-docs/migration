## October 2026
{: #migration-oct2026}
{: release-note}

New! {{site.data.keyword.cloud_notm}}{{site.data.keyword.mh_short}} is now available
:   {{site.data.keyword.mh_short}} is now available in the {{site.data.keyword.cloud_notm}} console. Your centralized platform for managing migrations across IBM Cloud products and services. It identifies the resources in your account that require action, helps you plan your migration path, and guides you through each step — with instructions, documentation, and tools for transitions such as deprecated services to modern replacements.

    - Virtual Servers migration
        :   Move Classic virtual server instances to VPC with profile-matched sizing, image capture tooling, and validated cutover steps. For more information, see [Virtual Servers](https://cloud.ibm.com/migration/servers){: external}.

    - Containers migration
        :   Migrate Red Hat OpenShift Kubernetes Service or IBM Kubernetes Service clusters from Classic to VPC-native networking, with guidance on Landing Zone setup, OADP-based workload migration, a migration wizard, and full testing and validation instructions. For more information, see [Containers](https://cloud.ibm.com/migration/clusters){: external}.

    - Databases migration
        :   Move to IBM Cloud Databases on Gen 2 VPC architecture, with per-engine migration approaches, private endpoint configuration, and automated operations from day one. For more information, see [Databases](https://cloud.ibm.com/migration/databases){: external}.
