# Understanding migration topics
{: #understanding-migration-topics}

In {{site.data.keyword.mh_short}}, migration topics represent specific transition paths and migration options available for your {{site.data.keyword.cloud_notm}} workloads. Explore and choose from multiple migration options to transition your resources to modern infrastructure and services.
{: shortdesc}

## Migration options
{: #migration-options}

{{site.data.keyword.mh_short}} provides guided migration paths across key infrastructure and service categories:

### Clusters
{: #clusters-migration}

- **Migration path**: Classic to VPC
- **Description**: Move container workloads from classic infrastructure to VPC to improve scalability, security, and network control.
- **Learn more**: For more information about container and cluster migrations, see [Migrating classic clusters to VPC clusters](/docs/containers?topic=containers-vpc-migration){: external}.

### Data services
{: #data-services-migration}

- **Migration path**: Classic to VPC
- **Description**: Modernize your database services on VPC infrastructure built for better performance, scale, and security.
- **Learn more**: For more information about data services modernization, see [Database migration overview](/docs/cloud-databases?topic=cloud-databases-migration-index){: external}.

### Key Protect
{: #key-protect-migration}

- **Migration path**: HPCS to Key Protect
- **Description**: Move your Hyper Protect Crypto Services workloads to Key Protect Dedicated before end of service.
- **Learn more**: For more information about migrating from Hyper Protect Crypto Services to Key Protect Dedicated, see [Migrating to Key Protect Dedicated](/docs/key-protect?topic=key-protect-migrate-hpcs){: external}.

### Servers
{: #servers-migration}

- **Migration path**: Classic to VPC
- **Description**: Transition virtual or bare metal servers from classic infrastructure to VPC for better performance, isolation, and cost transparency.
- **Learn more**: For more information about transitioning servers from classic to VPC, see [Migrating classic virtual servers to VPC](/docs/vpc?topic=vpc-migrating-classic-vsis){: external}.
