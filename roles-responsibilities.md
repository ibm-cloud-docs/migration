# Roles and responsibilities
{: #roles-responsibilities}

Each migration involves multiple stakeholders across IBM Cloud teams and customer organizations. Use this reference to identify who is responsible for what across the planning, execution, and post-migration phases.
{: shortdesc}

## Roles overview
{: #roles-overview}

The following table describes each role and their key responsibilities.

| Team | Role | Key responsibilities |
| ---- | ---- | ----------------- |
| Migration Hub Product Team | Builds and maintain the Migration Hub platform | - Design and deliver the Migration Hub experience, including in-task support entry points \n - Ensure the Support Center can receive and route migration-originated requests \n - Define & curate the Service team engagement process \n - Publish Migration Hub data for service team consumption |
| Service Product Team | Own the migration, defines requirements, communicates deadlines | - Define migration requirements, scope, and customer deadlines \n - Author and publish migration tasks in the Migration Hub through the service engagement process \n - Provide technical support and engagement with customers using their migration topics \n - Monitor migration completion rates and adjust communications as needed |
| IBM Cloud Customer | Complete the migration | - Review migration tasks and understand requirements and deadlines \n - Complete required migration steps within the Migration Hub \n - Raise blockers or issues as needed for the migration topics \n - Validate that migrated resources are functioning correctly post-migration |
| IBM Cloud Support | Initial migration triage and fast-pass to service teams | - Receive and triage support requests originating from Migration Hub \n - Ensure Basic plan customers have a supported path to help during IBM-mandated migrations \n - Escalate to the service product team when blockers require platform-side action |
| CSM / TAM / Account Team | Advocate customers for navigating complex migrations | - Proactively notify Premium customers of upcoming migration tasks \n - Coordinate migration planning and timeline management for strategic accounts \n - Serve as an escalation path when standard support is insufficient \n - Provide post-migration follow-up to confirm customer satisfaction
